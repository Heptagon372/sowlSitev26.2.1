S.OWL 활동

배우는 사람과 알려주는 사람이 계속 바뀝니다. 그게 우리가 성장하는 방식입니다. 카드를 눌러 자세히 보세요.

01 · SEMINAR

기술 세미나

자유 주제로 기술과 서비스를 조사해 부원 앞에서 발표합니다. 발표를 준비하며 지식이 정리되고, 듣는 사람의 시야가 넓어집니다.

매월 수요일 18:10 동아리방 전원 참여
Process
  1. 주제는 자유 — 새로 배운 기술, 삽질기, 파보고 싶던 서비스 전부 OK
  2. 15~20분 발표 + 자유 Q&A, 부담은 낮게 질문은 뾰족하게
  3. 발표 자료는 회원 자료실에 아카이빙 — 기수가 지나도 남습니다
You Get
  • 사람들 앞에서 기술을 설명해 본 경험 — 발표·면접 대비
  • 배운 것을 글과 슬라이드로 정리하는 습관
  • 내 전공 밖 기술까지 훑어보는 시야
02 · HACKATHON

미니 해커톤

학기당 1회, 기획부터 배포까지 하루 만에. 한정된 시간 안에 실제 동작하는 서비스를 만들어내는 S.OWL의 축제입니다.

학기 1회 1박 2일 팀 단위
Process
  1. 즉석 팀 빌딩 — 기획·디자인·개발이 섞이도록 팀을 짭니다
  2. 밤샘 개발 — 만든 것은 동아리 서버랙에 바로 배포합니다
  3. 아침 데모 데이 — 전원 시연, 투표와 시상까지
You Get
  • 실제로 돌아가는 서비스 하나 — 포트폴리오 재료
  • 기획부터 배포까지 팀 개발 사이클 경험
  • 밤새 같이 구른 팀원 — 제일 빨리 친해지는 법
03 · STUDY

스터디 그룹

혼자면 어렵지만 같이 하면 되는 것들. 알고리즘부터 프레임워크까지 원하는 주제를 직접 열거나 참여할 수 있습니다.

상시 운영 온·오프라인 병행 개설 자유
Process
  1. 학기 초 주제 공모 — 원하는 스터디를 직접 개설할 수 있습니다
  2. 주 1회 정기 모임 — 진도와 기록은 스터디장이 관리
  3. 결과물과 정리 노트는 스터디 자료실에 차곡차곡
You Get
  • 혼자서는 못 끝냈을 커리큘럼 완주 경험
  • 같이 막히고 같이 뚫는 동료
  • 기록으로 남는 학습 흔적 — 포트폴리오 강화
04 · LECTURE

번개 특강

Git 플로우, 리눅스 명령어, API 키 관리처럼 수업에서 안 알려주는 실무 팁을 1시간 안에 압축해서 전달합니다.

비정기 · 수시 1시간 압축 Q&A 중심
Process
  1. 단톡에 "이거 아는 사람?"이 뜨면 특강이 잡힙니다
  2. 아는 부원이 그날 저녁 화이트보드 앞에 섭니다
  3. Git 플로우 · 리눅스 · 배포 · API 키 관리 같은 실전 주제
You Get
  • 수업에선 안 가르쳐주는 실무 감각
  • 모르면 바로 물어보는 문화
  • 가르치는 쪽이 되어보는 경험 — 다음 강사는 당신
